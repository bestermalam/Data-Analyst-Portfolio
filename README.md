## 2. SQL Sales Data Analysis

### Project Overview
Analyzed a fictional Zambian retail company's sales data using MySQL to investigate revenue, product performance, city-level sales, and customer purchasing patterns.

### Objectives
- Calculate revenue using SQL queries.
- Identify highest-revenue products.
- Analyze sales performance by city.
- Identify top-spending customers.
- Calculate average transaction values.

### Tools Used
MySQL Server 8.0, MySQL Workbench, SQL.

### SQL Techniques
- SELECT and WHERE
- ORDER BY
- GROUP BY and HAVING
- SUM, COUNT, AVG, MIN, MAX
- INNER JOIN
- Subqueries
- Primary and foreign keys

### Key Findings

| Metric | Result |
|---|---|
| Total Revenue | K65,700 |
| Transactions | 10 |
| Units Sold | 21 |
| Average Transaction | K6,570 |
| Highest-Revenue Product | Laptop - K25,500 |
| Highest-Revenue City | Lusaka - K30,300 |
| Highest-Spending Customer | John Banda - K20,500 |

### Business Recommendations
- Investigate demand for high-revenue products.
- Explore opportunities in Lusaka.
- Improve sales of lower-performing products.
- Consider customer loyalty initiatives.

Note: This project uses fictional retail data for learning and demonstration.

## 4. Python Sales Data Analysis

### Project Overview
Used Python, Pandas, and Matplotlib in Google Colab to clean, analyze, and visualize sales transaction data.

The dataset contains 20 valid sales transactions from September 2026.

### Objectives
- Import and clean sales data.
- Identify missing and invalid records.
- Calculate sales KPIs.
- Analyze revenue by product and category.
- Investigate salesperson performance.
- Produce business charts.

### Tools Used
Python, Pandas, Matplotlib, Google Colab, Microsoft Excel, CSV.

### Data Cleaning Process
1. Imported the dataset using Pandas.
2. Identified blank rows and summary records.
3. Removed non-transaction rows.
4. Validated transaction records.
5. Calculated KPIs.
6. Exported clean data to CSV.

|---|---|
